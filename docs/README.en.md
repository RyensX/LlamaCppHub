# LlamaCppHub

[中文](../README.md) | **English**

LlamaCppHub is a convenient and good-looking user interface shell for `llama.cpp`, making it easy to manage `llama.cpp` runtime configurations.

Unlike LM Studio and similar applications, this software is only a shell and does not bundle a `llama.cpp` runtime. This lets you freely combine it with different `llama.cpp` branches to maximize performance.

> Most of the code for this software was also written using Qwen3.6-35B-A3B deployed locally. It is both convenient for local inference and useful for testing local model capabilities.

## Features

- **Configuration Management**
  - Manage multiple configurations
  - Edit and duplicate configurations easily
- **llama.cpp Settings**
  - Set a global `llama.cpp` executable
  - Override the `llama.cpp` executable per configuration
- **Launch Arguments**
  - Configure official arguments quickly
  - Add raw custom arguments for features from different `llama.cpp` branches
  - Run pre-start commands
  - Preview the final service startup command
- **Instance Runtime**
  - Start and stop local `llama.cpp` instances
  - View instance PID, runtime status, and live logs
  - Open Web Chatbox quickly
- **Resource Monitoring**
  - Display CPU, GPU, RAM, and VRAM usage while a configuration is running
  - Observe resource changes with trend charts
- **Desktop Experience**
  - System tray and background running
  - Chinese and English interface
  - Light and dark themes

## Tech Stack

- **Desktop Framework**: Tauri 2
- **Frontend**: React 18, TypeScript, Vite
- **Backend**: Rust
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Internationalization**: i18next, react-i18next
- **Charts**: Recharts
- **Icons**: lucide-react

## Requirements

Before development or building from source, prepare:

- Node.js and npm
- Rust toolchain
- System dependencies required by Tauri 2
- A usable `llama.cpp server` executable

> Tauri system dependencies vary by operating system. Please install the dependencies required for your development platform.

## Quick Start

Install dependencies:

```bash
npm install
```

Start the desktop app in development mode:

```bash
npm run tauri:dev
```

If you only need to start the frontend development server:

```bash
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite frontend development server |
| `npm run build` | Run TypeScript checks and build frontend assets |
| `npm run tauri` | Invoke the Tauri CLI |
| `npm run tauri:dev` | Start the desktop app in development mode |
| `npm run tauri:build` | Build production desktop artifacts |

## Production Build

Run:

```bash
npm run tauri:build
```

Build artifacts are generated by Tauri. The output directory and package format depend on your operating system and the bundle configuration in `src-tauri/tauri.conf.json`.

## Basic Workflow

1. Open LlamaCppHub.
2. Configure the global `llama.cpp server` executable path in Settings.
3. Create a new configuration, then set its name, model file path, and launch arguments.
4. Add pre-start commands or custom arguments if needed.
5. Confirm the final startup command in the command preview.
6. Start the local server instance for the configuration.
7. View live logs, resource usage, and trend charts on the detail page.
8. Stop the instance when finished.
